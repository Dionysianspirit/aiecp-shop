## 演示建议（5 分钟走完整流程）

1. **消费者 buyer001 登录**：首页看「智能选品·为你推荐」（带推荐理由与召回来源）→ 打开任意商品 → 看「智能组货」组合方案 → 右下角 🤖 问「我的订单到哪了」（工具调用返回真实订单）或「退货政策」（RAG 带引用）
2. **加购下单**：一键加购组合 → 结算用券 → 提交（锁库存）→ 支付 → 我的订单看状态流转
3. **商家 shop001 登录**：品类 JSON 导入 → 点「校验」看 dry-run 衍生能力预览 → 点「载入示例模板」后「正式导入」→ 商品发布页选新叶子品类，看**动态表单** → 发布商品
4. **管理员 admin 登录**：AI 中台治理 → **关闭大模型网关** → 回商城再问客服/看推荐，验证全线降级且响应带 `degraded` 字段 → 重新开启恢复

## 本地运行

```bash
cd aiecp-shop
python3 -m http.server 8077     # 或任意静态服务器
# 浏览器打开 http://127.0.0.1:8077
```

也可直接双击 `index.html` 离线打开（file:// 协议同样可用）。

## 技术说明

- **零依赖静态实现**：无框架、无构建、无外部 CDN；`assets/js/` 按设计报告分层 —— `category-engine.js`（品类引擎）、`ai.js`（AI 能力中台：模板方法 + 策略 + 工厂 + 降级）、`api.js`（服务层，统一响应体 `{code,message,data,traceId}`）、`db.js`（localStorage 落仓）、`seed.js`（演示数据）、`views.js/app.js`（表现层）
- 大模型网关为本地规则推理模拟（课程演示无需 API Key）；AI 输出经安全护栏过滤（NFR-10）
- 数据全部存于本机浏览器，右上角「退出」不影响数据；如需重置演示数据，在控制台执行 `localStorage.clear(); DB.init(true)` 后刷新

## 目录结构

```
aiecp-shop/
├── index.html                  # SPA 外壳
└── assets/
    ├── css/style.css           # 全站样式
    └── js/
        ├── seed.js             # 种子数据（品类树/商品/用户/知识库/关联规则）
        ├── db.js               # localStorage 存储层
        ├── category-engine.js  # 品类引擎：语法/语义校验、建树、动态表单、索引映射
        ├── ai.js               # AI 能力中台：客服/选品/组货 + 护栏 + 降级契约
        ├── api.js              # 服务层：鉴权/交易/订单状态机/库存/运营
        ├── views.js            # 视图：商城 + 商家后台 + 运营端
        └── app.js              # 路由、会话、交互
```
